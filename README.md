# Grover Adaptive Search

This repository stores the code and results for:

CITE-PAPER

To install please pull repo then navigate to the root directory of the repository and run:

```pip install .```

For the quantum circuits required to build Dicke states the code in [link](https://github.com/andre-juan/dicke_states_preparation/) was modified (shared under an Apache License 2.0). If using this functionality please cite the [repository](https://github.com/andre-juan/dicke_states_preparation/) and the [work](https://doi.org/10.1007/978-3-030-25027-0_9). This only affects the `dicke.py` file in this repo.

Please see:
- `notebooks` for an overview of the tools provided alongside examples.
- `results` to see the jupyter notebooks used to generate the results in the paper.
